# Bundled fonts and their licences

Lyric Studio bundles these open-source font families as npm packages (Fontsource). Each package keeps
its own licence file (the SIL Open Font License 1.1 unless noted), at the path shown under
packages/video/. The fonts may be used in videos you publish; the licence travels with the font files.
Your own fonts go in workspace\fonts (D:\videomaker\workspace\fonts); their licences are yours to check.
