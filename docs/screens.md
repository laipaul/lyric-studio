# Screens

_Part of the project brief (CLAUDE.md links here). Every screen of the studio: Library, Song page tabs, Storyboard, Textboard, Collections, Content board, Studio. Moved word for word from CLAUDE.md on 30 Oct 2026; keep it up to date when this area changes._

Screens (Step 6, in the Life Lyrics look: dark, Cinzel headings, accent pink):
- **Feature icons** (1 Nov 2026; apps/studio/src/lib/feature-icons.tsx FEATURE, FeatureIcon, PlatformMark; data-feature-icon, data-platform-mark): one icon and colour per feature, the same on every screen: Song music note white, Theme palette pink (brand), Clips film teal, Collection a stack teal, Lyrics and card text "T" amber, steps Prepare ✓ / Shape ◇ / Make clapperboard / Review eye / Post paper plane, Automatic wand. Platform marks are plain shapes in each platform's colour (not the platforms' logos), shown before the platform's name on Library cards.
- **Library** (start page): **New song** as the first tile of the grid (data-new-song-tile, 1 Nov 2026, like Themes, Collections and Releases; no button at the top), then song cards (cover, title on up to 2 lines, artist/EP, per-platform chips and status) with search; Step H (src/library-status.ts, pure): one colour per chip — grey not made (or all discarded), amber made but not approved ("to review"), green an approved video in the latest run, or in an older run when the latest kept none (the count = approved in any run; a new unreviewed render turns the chip amber again), red failed / stopped (reasons and Resume in its popover), pulsing while rendering; "Standard" only when the song has some; full labels that never truncate (wrapping chips); a summary line ("2/5 ready · 1 to review · 1 error", "No videos yet"); one action per card: Generate (?tab=generate, no videos), Fix (?tab=videos, a failed run), Resume (a stopped run, /api/runs/resume), Review (?tab=videos, videos to review), none when everything made is approved; "Same cover as …" when another song has the very same cover picture (by content); the song's theme under the artist line (data-card-theme; listSongs first puts every song on a theme); "Deleted songs (N)" under the cards (data-deleted-songs; folded) with Restore per song (data-song-restore); filters All · No videos · Needs review · Errors · Ready (with counts; Ready = something approved and nothing to review, failed or rendering) and Sort: Last made (default; added counts when never made) · Title · Date added; "+ New song" (WAV/MP3 + lyrics.txt required, or "Instrumental" with an optional story.txt; cover, hints .lrc, title, artist with a dropdown of used artists, EP optional) creates or updates the project (found by the song's content). While songs or collections still use the old folders, a banner offers "Preview" (dry run) and "Migrate" (6.2c-1).

- **Post downloads** (11 Nov 2026, decided with the user; lib/save-file.ts, ready-to-post.tsx): every file button of the Post panel (Video, Captions (.srt), Thumbnail, Cover, publish.txt; data-save-file, data-save-name) opens a "Save as" picker (File System Access API, Chrome / Edge) in the last folder used for this song and platform (else this song's folder, else the last parent folder, else Downloads); other browsers: a normal download.
