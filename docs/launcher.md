# Starting and stopping the app

_Part of the project brief (CLAUDE.md links here). pnpm dev, Start / Stop Lyric Studio.cmd, rebuilds, PWA and app icons. Moved word for word from CLAUDE.md on 30 Oct 2026; keep it up to date when this area changes._

- One `pnpm dev` command starts studio + worker + audio service; "Start Lyric Studio.cmd" / "Stop Lyric Studio.cmd" do the same in the background (production build, rebuilt when the code version changed: git commit + local changes in apps/studio and packages, scripts/app-version.mjs, stamped in apps/studio/.next/lyric-studio-build.txt and reported by /api/health; Start restarts a running older build, prints each step and the commit it runs; Stop kills the app:serve process tree from logs/lyric-studio.pid and waits for ports 3000/8001; `pnpm app:rebuild` = clean rebuild) and open the app; the studio listens on 127.0.0.1 only (STUDIO_HOST to change); installable PWA (manifest, icons made from workspace\brand\logo.png, service worker), no internet needed; app icons: the logo's transparent padding cropped so it fills ~90%, every size rendered from the full logo (Lanczos), a multi-size .ico (16, 24, 32, 48, 64, 128, 256) for the shortcut and the window, brand.json appIcon.style "logo" (default) or "tile" (rounded square in the accent colour)
